Description

EN — short. Typing practice with real code, for programmers and keyboard enthusiasts. Free on Google Play.

ES — corta. Práctica de mecanografía con código real, para programadores y aficionados al teclado. Gratis en Google Play.

EN — long. Most typing trainers drill the same lorem ipsum forever. Ridge drills source code instead: pick a snippet from Go, Rust, Python, SQL, Bash, Zig, Swift, Kotlin, TypeScript or two dozen other languages and type it inside an editor that highlights syntax as you go, with mistakes counted per key. It is also a keyboard enthusiast's tool: the profile screen renders your keyboard in three dimensions from real key geometry, and the built-in editor changes keycap shapes, light transmission, case colours, per-key legends and remaps, then plays one of eleven firmware RGB effects. Everything runs locally — no account, no ads, no analytics.

ES — larga. La mayoría de los retractores de tecleo te hacen escribir siempre los mismos tres párrafos de texto de relleno. Ridge practica código fuente: elige un fragmento de Go, Rust, Python, SQL, Bash, Zig, Swift, Kotlin, TypeScript o dos docenas de lenguajes más y escríbelo dentro de un editor que resalta la sintaxis mientras escribes, con los errores contados por tecla. Además es una herramienta para aficionados al teclado: la pantalla de perfil dibuja tu teclado en tres dimensiones a partir de la geometría real de las teclas, y el editor integrado cambia la forma de las keycaps, la transmisión de la luz, el color de la carcasa, las leyendas y los remapeos, y activa uno de los once efectos RGB de firmware. Todo funciona en local: sin cuenta, sin anuncios y sin analíticas.

Usage

Please use the supplied files as-is instead of recomposing them: they are the only versions that keep the mark, the palette and the type consistent. Flat surfaces only — the product itself uses no gradients and no shadows. Do not recolour the mark or place it on a busy background.

Usa los archivos proporcionados tal cual, sin recomponerlos: son las únicas versiones que mantienen coherentes el símbolo, la paleta y la tipografía. Solo superficies planas: el producto no usa degradados ni sombras. No recolorees el símbolo ni lo coloques sobre un fondo con mucho detalle.
